Política de privacidad

Última actualización: 6 de octubre de 2026.

ANT0FF Northbots desarrolla y opera asistentes digitales para negocios. Esta política explica cómo se trata la información cuando una persona interactúa con un asistente de ANT0FF mediante un canal autorizado, como Instagram.

Información que puede procesarse

Podemos procesar el identificador público del canal, el contenido de los mensajes que una persona envía voluntariamente y los datos técnicos imprescindibles para responder y mantener la conversación. No solicitamos contraseñas ni datos de pago mediante los asistentes.

Finalidad

Usamos la información únicamente para responder consultas, prestar el servicio solicitado, mantener la seguridad y mejorar la configuración del asistente. No vendemos información personal.

Conservación y seguridad

Aplicamos medidas razonables para limitar el acceso a la información. Conservamos los datos solo durante el tiempo necesario para las finalidades indicadas o cuando una obligación legal exija conservarlos.

Compartición

La interacción puede involucrar a la plataforma de mensajería elegida por la persona y a proveedores técnicos necesarios para operar el servicio. Cada plataforma aplica sus propias políticas de privacidad.

Tus derechos y contacto

Podés solicitar acceso, corrección o eliminación de tus datos siguiendo las instrucciones de la sección siguiente. Para consultas de privacidad, escribinos por mensaje directo a @antoffnorthbots.

Control de tu información

Instrucciones para eliminar datos

Para solicitar la eliminación de datos vinculados a una conversación, enviá un mensaje directo a @antoffnorthbots con el texto: “Solicito eliminar mis datos”.

Para identificar la solicitud, indicá el nombre de usuario del canal desde el que escribiste. Confirmaremos la recepción y eliminaremos o anonimizaremos los datos asociados, salvo que debamos conservar alguno por una obligación legal, seguridad o prevención de fraude.

También podés revocar el acceso de una aplicación desde la configuración de Apps y sitios web de Instagram.
