Instrucciones para eliminar datos

Enviá un mensaje directo a @antoffnorthbots con el texto: “Solicito eliminar mis datos”.

Para identificar la solicitud, indicá el nombre de usuario del canal desde el que escribiste. Confirmaremos la recepción y eliminaremos o anonimizaremos los datos asociados, salvo que debamos conservar alguno por obligación legal, seguridad o prevención de fraude.

También podés revocar el acceso de una aplicación desde la configuración de Apps y sitios web de Instagram.
